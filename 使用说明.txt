GHide v1.3.2
===========

功能
----
1. 双击 Windows 桌面空白处，可隐藏全部桌面图标；再次双击即可恢复显示。
   双击桌面图标、任务栏或普通应用窗口不会触发。
2. 程序运行时，底部任务栏自动变为全透明（仅影响外观，不影响使用）。

使用方法
--------
1. 双击 GHide.exe 运行，无需安装。任务栏透明模块已内嵌在 exe 中，
   只拷贝/下载 GHide.exe 一个文件即可完整使用。
2. 程序启动后常驻任务栏右下角的系统托盘。
3. 右键托盘图标，可以：
   - 手动切换桌面图标显示状态；
   - 开关“任务栏透明”；
   - 设置开机自动启动；
   - 打开诊断日志、查看“关于”或退出。

说明
----
- v1.3.2：taskbar_transparency.dll 已内嵌进 exe（单文件分发）；任务栏透明失败时
  托盘会气泡提示原因（不再静默）。若在 exe 同目录放置 taskbar_transparency.dll，
  运行时优先使用同目录版本。
- v1.3.1：版权署名统一为 Copyright © 2026 Wanting. 保留所有权利。
- v1.3.0：正式更名为 GHide，程序文件、标识与文档同步更新。
- v1.2.1：程序通过托盘菜单正常退出时，会恢复桌面图标显示（仅恢复由本程序隐藏的图标；
  若用户通过其他方式手动隐藏，退出时不会打扰）。若被任务管理器强制结束，桌面图标不会恢复。
- 任务栏透明在退出程序时自动恢复原样（包括任务管理器结束或崩溃时，也会自动还原）；
  若 Explorer 重启（任务栏重建），程序会自动重新应用透明效果。
- 程序只控制桌面图标的显示状态，不会删除、移动或修改桌面文件。
- 构建时需要 MSYS2（用于编译 taskbar_transparency.dll）；仅使用已编译版本则无需安装。

系统要求
--------
Windows 10 或 Windows 11，支持高 DPI 与多显示器缩放。

提示
----
程序只控制桌面图标的显示状态，不会删除、移动或修改桌面文件。
如果 Windows SmartScreen 提示未知发布者，这是因为程序没有商业代码签名；
确认文件来自 https://github.com/gwanting/GHide 后，
可选择“更多信息”→“仍要运行”。

问题诊断
--------
如果切换失败，请右键托盘图标选择“打开诊断日志”。
日志默认位于：%LOCALAPPDATA%\GHide\GHide.log
